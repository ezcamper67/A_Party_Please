# A Party Please

Website for apartyplease.com, hosted on GitHub Pages.

- `index.html`: home page
- `characters.html`: character roster
- `css/styles.css`, `js/main.js`: styles and scripts
- `images/`: photos used on the site

The booking form sends through Web3Forms to apartyplease@gmail.com.
The previous site is saved on the `backup-old-site` branch.
